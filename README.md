# rust_fantasy_4X

A fantasy 4X strategy game written in Rust. It starts from a Master of Magic-style design (two planes, wizards and spell-casting, heroes, tactical battles) but is expected to deviate over time. It is a gameplay-inspired reimagining, not a port: no original code, data or art is used.

- Design: [`docs/design.md`](docs/design.md)
- Status: design phase, no code yet.
