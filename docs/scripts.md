# Scripts

Every script in `scripts/`, with what it does. Run any of them with `--help` for its options. Add a
row when you add or change a script (see `CLAUDE.md`).

| Script | What it does |
|---|---|
| `test_changed.py` | Runs only the tests the changes since a git ref (default `HEAD`, worktree and untracked files included) can break: the changed crate and its dependents, the core modules that mention a changed module, and the slow console and learn tests only when their area changed. `content/` and `Cargo` changes run everything; `--all` is `cargo test --workspace` (run before a commit), `--slow` adds the slow tests, `--dry-run` prints the plan. |
| `sound_table.py` | Writes `content/sound.ron`: the cast sound of each spell (byte 30 of a `SPELLDAT.LBX` record), the music of each global enchantment, and each unit's move and melee sound (set by ReMoM's `NEXTTURN.c`), by the ids of `spells.ron` and `units.ron`. Needs the author's game folder and the ReMoM clone; safe to run again. |
| `item_icons.py` | Writes the original's item picture number (`ITEMDATA.LBX`, byte 30 of a record) as `icon: N` on each row of `content/items.ron`; safe to run again; `--dry-run` reports only. |
| `untested_content.py` | Lists the content ids (spells, units, buildings, abilities, items, ...) that no test of the workspace names, with counts per file; `--names` lists the ids, `--only FILE` narrows it. A start for the test audit (task 302): an id covered only by a loop over the content shows up too. |
| `archive_done_tasks.py` | Moves finished tasks (summary or title marked "(done)", or struck through) from `docs/TASKS.md` to `docs/TASKS-DONE.md`, keeping the numbers and the done list in ascending order. `--dry-run` lists what would move. |
| `cool_run.sh` | Runs a long command (training, soak runs) at low priority and pauses it while the Mac is under thermal pressure; `--state` prints the thermal state. Builds `thermal_state` when missing. |
| `fix_wrapper_calls.py` | After deleting `Game` wrapper methods, rewrites their callers to go through `game.units()` or `game.economy()`, driven by the compiler's "no method named" errors (task 198). |
| `import_mom.py` | Imports Master of Magic data from the author's own copy of the game and a ReMoM clone into `content/` (rules data, committed) and `content-local/` (help text and other copyrighted prose, never committed); writes an import report (the local files include `wizard_texts.ron`, the ready-made wizards' names and descriptions, `hero_names.ron`, five original names per hero unit from `NAMES.LBX`, and `event_texts.ron`, the random events' messages from `EVENTMSG.LBX`). It writes only the local files; the game data (`races`, `units`, `buildings`, `spells`, `abilities`, `items`, `realms`, `level_paths`, `rules`) is kept by hand in `content/`. |
| `list_ogbugs.py` | Indexes the `OGBUG` comments in the ReMoM clone (places where the original departs from its manual) into `content-local/`, as a worklist for `docs/help-vs-implementation-conflicts.md`. |
| `grey_neutral.py` | Turns the neutral player's colour from brown to grey in the local art: the sixth row of `map/banners.tsv`, the neutral cities, towers and unit backgrounds (only the banner's pixels), and the minimap's neutral colour. Run it after `extract-art` (which writes the original's brown again); running it twice changes nothing. Needs Pillow (`.venv`). |
| `make_banner_colours.py` | Makes the five more player colours (pink, brown, turquoise, dark blue, orange; task 381) in `assets-local/art`: the rows of `map/banners.tsv` and `map/tiles/minimap.tsv` (the neutral colour moves to 10), the cities, towers, node auras and unit backgrounds in each new colour, and the wizards' gems (`lilwiz` 100 and up). Run after `extract-art`. Needs Pillow (.venv). |
| `make_banner_flags.py` | Makes the small flags of the banner step into `assets-local/art/banner_flags/`: the five flags of the original's picture (`newgame` 46) cut from the screen's ground at half size (entries 0 to 4), and five more with the hue turned (5 to 9: pink, brown, turquoise, dark blue, orange; `--turn` changes the angles). Needs Pillow (`.venv`) and the extracted art; the output is derived from the original's art, so it stays local. |
| `make_spell_art.py` | Makes the animations of spells the original has no picture for, from pictures it has: Ice Bolt (Fire Bolt's frames, orange to light blue, mirrored so the bolt comes from the left) and Petrify (Change Terrain's sparkles, `specfx` 8, green to dark brown), into `assets-local/art/spells/<spell>/`. Needs Pillow (`.venv`) and the extracted art; the output is derived from the original's art, so it stays local. |
| `make_app.sh` | Builds the local macOS app `target/Fantasy4X.app` (release build of `f4x-client` plus a copy of `content/`, `content-local/` and `assets-local/art`). For this machine only: it carries the local-only art and text. |
| `train_battle.sh` | Trains the battle AI unattended: builds the trainer, runs it through `cool_run.sh` into a fresh `models-local/NAME` folder (never overwrites), picks the best checkpoint by its held-out reward with the advice hidden, writes `STATUS`, `summary.txt` and `best.bpk`. `--detach` runs it in the background (nohup, caffeinate), `--notify` shows a macOS notification at the end, `--dry-run` prints the plan. |
| `tournament.sh` | Runs a neural-against-neural tournament of battle networks unattended (`PLANNED.md` item 25): builds the tools, picks parents from checkpoints by a round robin, makes nudged and noisy variants, plays a Swiss stage and a knockout through `cool_run.sh` into a fresh `models-local/tournament-NAME` folder (`--resume` continues one), and writes the standings, profiles, bracket and the champion's weights. `--detach`, `--notify`, `--dry-run`. |
| `thermal_state.swift` | Prints the macOS thermal pressure level (nominal, fair, serious, critical, or unknown); built to `thermal_state` and used by `cool_run.sh`. |
| `palette_swap.py` | Recolours the 14 wizard portraits by region (hair, clothes, backdrop; faces protected), three variants each, into `assets-local/palette-swap/` plus a contact sheet. Needs the extracted art and Pillow (`.venv`, `requirements.txt`). Local-only output. |
