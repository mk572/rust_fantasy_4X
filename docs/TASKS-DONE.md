**654. (done) Remove trivial wrappers.** Asked for on 17 November 2026. Two kinds, handled differently. (1) **Trivial wrappers**: a function (or method, or `const`/type alias used as a function) whose body only calls another function with the same arguments, in the same or a changed order, with no check, no conversion, no default and no change of name that adds meaning (`fn unit_pos(&self, u) -> Option<Position> { self.units().unit_position(u) }`, `fn run(ai, game, events) { other::run(ai, game, events) }`). They are removed: the callers call the target, the wrapper is deleted, and its tests and docs go with it. A forwarder that is the *public interface* of a module on purpose (it keeps the internals private, `docs/design.md` section 2, the crate boundaries) or that a trait requires stays, and is not counted.
